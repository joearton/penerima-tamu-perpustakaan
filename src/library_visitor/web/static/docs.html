1. Ringkasan

Aplikasi Penerima Tamu menyediakan API JSON untuk mendaftarkan anggota beserta wajahnya dari perangkat lain di jaringan lokal. Laman registrasi web memakai API yang sama.

Alamat dasarhttps://<IP-PC>:<port> (port default 8443, lihat Pengaturan → Registrasi via Web)
FormatJSON UTF-8, baik permintaan maupun respons
AksesHanya alamat jaringan lokal (10.x, 172.16–31.x, 192.168.x, loopback). Permintaan dari luar ditolak 403.
TLSSertifikat dibuat sendiri oleh aplikasi; klien perlu mempercayainya atau melewati verifikasi (mis. curl -k).
PrivasiFoto wajah hanya diproses lalu dibuang; yang disimpan hanya embedding wajah.

2. Autentikasi

  1. Kirim POST /api/login berisi PIN admin aplikasi.
  2. Server mengembalikan cookie sesi pt_session (HttpOnly, Secure, SameSite=Strict) yang berlaku 8 jam.
  3. Sertakan cookie itu di setiap permintaan berikutnya.

Setiap POST wajib membawa header berikut (perlindungan CSRF):

Content-Type: application/json
X-Requested-With: penerima-tamu

Setelah 5 kali PIN salah dari alamat IP yang sama, IP itu dikunci 60 detik (429). API hanya aktif bila PIN admin sudah diatur.

3. Endpoint registrasi

Metode & pathLoginFungsi
POST /api/login–Masuk dengan PIN, mengembalikan cookie sesi
POST /api/logout–Mengakhiri sesi
GET /api/session–Cek apakah sesi masih berlaku
GET /api/metayaInfo lokasi, daftar kategori, jumlah sampel wajah
GET /api/search?q=yaCari anggota (lokal + direktori) untuk auto-complete
GET /api/lookup?no=yaData satu anggota berdasarkan nomor
POST /api/registeryaSimpan anggota dan (opsional) wajahnya

POST /api/login

{"pin": "<PIN-admin>"}
→ 200 {"ok": true}            + Set-Cookie: pt_session=...
→ 401 {"error": "PIN admin salah"}

GET /api/session

→ 200 {"authenticated": true}

GET /api/meta

→ 200 {
  "library": "Nama lokasi",
  "institution": "Nama institusi pemegang lisensi",
  "categories": ["Mahasiswa", "Dosen", "Staf", "Umum"],
  "samples": 5,          // jumlah sampel wajah yang disarankan
  "lookup": true,        // direktori anggota tersedia
  "search": true         // pencarian direktori tersedia
}

GET /api/search?q=<teks>

Minimal 2 karakter (pencarian direktori minimal 3). Maksimal 10 hasil.

→ 200 {"results": [
  {"member_no": "2301001", "name": "Siti Aminah", "category": "Mahasiswa",
   "unit": "Informatika", "status": "Aktif", "registered": true, "has_face": true}
]}

GET /api/lookup?no=<nomor>

Mencari di data lokal lalu di direktori anggota. photo berisi foto profil dari direktori (data URL) bila tersedia; hanya untuk ditampilkan.

→ 200 {"found": true, "member_no": "2203117", "name": "Dewi Lestari",
       "category": "Mahasiswa", "unit": "Manajemen", "status": "Aktif",
       "registered": false, "has_face": false, "source": "direktori",
       "photo": "data:image/jpeg;base64,..."}
→ 200 {"found": false, "photo": ""}

POST /api/register

FieldKeterangan
member_no, nameWajib
categorySalah satu dari categories; selain itu menjadi Umum
unitProdi / unit kerja (opsional)
imagesDaftar foto JPEG/PNG base64 (boleh data URL), maksimal 20 foto @ 3 MB. Kosong = simpan data saja.
consentWajib true bila ada foto (persetujuan data biometrik)
confirm_duplicatetrue untuk tetap menyimpan walau wajah mirip anggota lain
from_directory, statusTandai data berasal dari direktori beserta statusnya

Setiap foto harus berisi tepat satu wajah yang cukup besar dan lolos anti-spoofing. Minimal 60% foto harus lolos.

→ 200 {"member_no": "2203117", "name": "Dewi Lestari", "face_saved": true, "samples": 6}
→ 409 {"error": "Wajah ini mirip dengan ...", "duplicate": "Budi Santoso", "score": 0.52}
→ 422 {"error": "Hanya 2 dari 7 foto yang bisa dipakai ...", "problems": ["Foto 3: wajah tidak terdeteksi", ...]}

4. Format galat

Semua galat berbentuk {"error": "pesan yang bisa ditampilkan"}, kadang dengan field tambahan.

KodeArti
400Data tidak lengkap / tidak valid
401Belum login atau PIN salah
403Bukan jaringan lokal, atau header X-Requested-With tidak ada
409Wajah mirip anggota lain (kirim ulang dengan confirm_duplicate)
413 / 415Data terlalu besar / bukan JSON
422Terlalu sedikit foto wajah yang memenuhi syarat (lihat problems)
429Terlalu banyak percobaan PIN; tunggu sebentar
502Direktori anggota tidak bisa dihubungi

5. Contoh curl

BASE=https://192.168.1.20:8443
H='-H Content-Type:application/json -H X-Requested-With:penerima-tamu'

# login, simpan cookie sesi
curl -k -c sesi.txt $H -d '{"pin":"<PIN-admin>"}' $BASE/api/login

# cari anggota
curl -k -b sesi.txt "$BASE/api/search?q=siti"

# daftarkan anggota beserta foto wajah
IMG=$(base64 -w0 wajah1.jpg)
curl -k -b sesi.txt $H $BASE/api/register -d "{
  \"member_no\": \"2203117\", \"name\": \"Dewi Lestari\", \"category\": \"Mahasiswa\",
  \"consent\": true, \"images\": [\"$IMG\", \"$IMG\", \"$IMG\"] }"

6. Integrasi direktori anggota

Opsional. Bila instansi memiliki sistem data anggota (mis. sistem akademik atau kepegawaian), aplikasi dapat mengambil data anggota dari sana. Sistem instansi cukup menyediakan endpoint read-only berikut, lalu alamat dan kredensialnya diisi di file .env aplikasi.

Variabel .envKeterangan
DIRECTORY_LOOKUP_URLWajib. URL dengan placeholder {nomor}, mis. https://contoh.ac.id/api/members/{nomor}/
DIRECTORY_API_KEY, DIRECTORY_API_SECRETDikirim sebagai header X-API-Key dan X-API-Secret
DIRECTORY_SEARCH_URLOpsional, untuk auto-complete
DIRECTORY_FACES_URLOpsional, galeri foto untuk tebakan identitas saat registrasi

Lookup (wajib)

GET {DIRECTORY_LOOKUP_URL dengan {nomor} terisi}
→ 200 {"status": true, "data": {
         "member_no": "2021010123", "name": "Siti Aminah", "category": "Mahasiswa",
         "unit": "Informatika", "status": "Aktif",
         "photo": "<JPEG base64 atau URL>"      // opsional, foto profil
       }}
→ 404 anggota tidak ditemukan · 401/403 kredensial ditolak · 429 batas laju

category dikenali sebagai Mahasiswa, Dosen, atau Staf; nilai lain menjadi Umum. Foto juga boleh dikirim lewat field photo_url atau picture. Kredensial hanya dikirim bila URL foto berada di host yang sama dengan URL lookup.

Pencarian (opsional)

GET {DIRECTORY_SEARCH_URL}?q=<teks>&limit=<n>
→ 200 {"status": true, "data": [<objek anggota seperti di atas>, ...]}

Galeri foto (opsional)

GET {DIRECTORY_FACES_URL}?page=<n>&per_page=100[&updated_since=<ISO8601>]
→ 200 {"status": true,
       "data": [{<objek anggota>, "photo": "<JPEG base64>", "photo_updated_at": "2026-10-01T08:00:00"}],
       "meta": {"current_page": 1, "last_page": 12, "total": 1150}}

Hanya field di atas yang dipakai; respons mentah tidak disimpan atau ditulis ke log. Berikan kunci API dengan hak akses seminimal mungkin (read-only, hanya endpoint ini).

7. Login admin OAuth2 / OpenID Connect

Opsional. Admin dapat masuk ke tab admin aplikasi desktop memakai akun dari penyedia identitas instansi (authorization code + PKCE S256, klien public tanpa secret, redirect loopback).

Variabel .envKeterangan
OAUTH_AUTHORIZE_URL, OAUTH_TOKEN_URL, OAUTH_USERINFO_URLEndpoint penyedia identitas
OAUTH_CLIENT_IDID klien public
OAUTH_REDIRECT_URIDefault http://127.0.0.1:8765/callback; daftarkan persis di penyedia identitas
OAUTH_SCOPE, OAUTH_LABELDefault openid profile email dan teks tombol login

Userinfo dibaca dari preferred_username (atau sub), name, dan groups. Username atau grup yang boleh masuk diatur di Pengaturan → Keamanan. Login ini hanya untuk aplikasi desktop, bukan untuk API di atas.
